## 1. Makalah 802.11

### 1.1. Abstrak

IEEE 802.11 adalah keluarga standar untuk **Wireless Local Area Network (WLAN)** yang dikembangkan oleh IEEE. Standar ini menjadi fondasi teknologi WiFi yang digunakan secara global. Makalah ini membahas arsitektur, jenis frame, versi standar, dan implementasi praktis dari 802.11.

**Kata Kunci:** 802.11, WiFi, WLAN, MAC Layer, Frame Structure, Access Point

---

### 1.2. Pendahuluan

#### 1.2.1. Latar Belakang

| Aspek | Keterangan |
|-------|------------|
| **Nama** | IEEE 802.11 |
| **Tahun Rilis** | 1997 |
| **Pengembang** | IEEE (Institute of Electrical and Electronics Engineers) |
| **Nama Komersial** | WiFi (dipopulerkan oleh Wi-Fi Alliance) |
| **Fungsi** | Standar komunikasi wireless untuk LAN |

#### 1.2.2. Mengapa 802.11 Penting?

```
📱 Smartphone    💻 Laptop        🏠 Smart Home
    ↓                ↓                ↓
    └─────────────── 802.11 ──────────┘
                   (WiFi)
```

#### 1.2.3. Karakteristik Utama

- **Frekuensi:** 2.4 GHz, 5 GHz, 6 GHz
- **Jangkauan:** 20-100 meter (indoor)
- **Kecepatan:** 2 Mbps - 46 Gbps
- **Mode:** Infrastructure, Ad-hoc, Mesh

### 1.3. Arsitektur 802.11

#### 1.3.1. Komponen Dasar

```
┌─────────────────────────────────────────────────────┐
│                ARSITEKTUR 802.11                    │
├─────────────────────────────────────────────────────┤
│                                                     │
│   ┌─────────────┐         ┌─────────────┐         │
│   │   Station   │  ◄──►   │  Access     │         │
│   │   (Client)  │   WiFi  │   Point     │         │
│   └─────────────┘         └─────────────┘         │
│          │                       │                  │
│          ▼                       ▼                  │
│   ┌─────────────┐         ┌─────────────┐         │
│   │   BSS       │         │   DS        │         │
│   │   (Basic    │         │  (Distribution│       │
│   │   Service   │         │   System)   │         │
│   │   Set)      │         │             │         │
│   └─────────────┘         └─────────────┘         │
│                                                     │
└─────────────────────────────────────────────────────┘
```

#### 1.3.2. Mode Operasi

| Mode | Deskripsi | Penggunaan |
|------|-----------|------------|
| **Infrastructure** | Client → AP → Network | Rumah, Kantor |
| **Ad-hoc (IBSS)** | Client ↔ Client | Peer-to-peer |
| **Mesh** | Multi-hop routing | Smart City |
| **Monitor** | Sniffing/packet capture | Security, Forensics |

#### 1.3.3. Service Set

```
BSS (Basic Service Set)
  └── 1 AP + 1+ Client

ESS (Extended Service Set)
  └── Multiple BSS dengan SSID sama

IBSS (Independent BSS)
  └── Client-to-client (Ad-hoc)
```

### 1.4. Struktur Frame 802.11

#### 1.4.1. Format Frame Umum

```
┌─────────────────────────────────────────────────────────────┐
│                        FRAME 802.11                         │
├───────────────┬─────────────────────────────────────────────┤
│ Frame Control │ Address 1     │ Address 2     │ Address 3  │
│ (2 bytes)     │ (6 bytes)     │ (6 bytes)     │ (6 bytes)  │
├───────────────┴───────────────┴───────────────┴────────────┤
│ Sequence Control │ Payload (variable)      │ FCS (4 bytes)│
│ (2 bytes)        │                         │              │
├──────────────────┴─────────────────────────┴───────────────┤
└─────────────────────────────────────────────────────────────┘
```

#### 1.4.2. Frame Control Field

```
┌─────┬─────┬─────┬─────┬─────┬─────┬─────┬─────┐
│ 2   │ 2   │ 4   │ 1   │ 1   │ 1   │ 1   │ 1   │
├─────┼─────┼─────┼─────┼─────┼─────┼─────┼─────┤
│Protocol│Type  │Subtype │ToDS │FromDS│More Frag│Retry│
├─────┼─────┼─────┼─────┼─────┼─────┼─────┼─────┤
│ Power │More Data│Protected│Order │
└──────┴─────────┴─────────┴──────┘
```

**Field Penting:**
- **Protocol Version:** Selalu 00
- **Type:** 00=Management, 01=Control, 10=Data
- **Subtype:** Menentukan jenis frame spesifik

#### 1.4.3. Jenis Address

| Address | Deskripsi | Panjang |
|---------|-----------|---------|
| **Address 1** | Destination MAC | 6 bytes |
| **Address 2** | Source MAC / BSSID | 6 bytes |
| **Address 3** | BSSID / SA | 6 bytes |

### 1.5. Jenis Frame 802.11

#### 1.5.1. Management Frames (Type 0)

| Subtype | Hex | Fungsi | Digunakan |
|---------|-----|--------|-----------|
| **Beacon** | 0x08 | Broadcast identitas AP | ✅ |
| **Probe Request** | 0x04 | Client cari AP | ✅ |
| **Probe Response** | 0x05 | AP respon probe | ✅ |
| **Authentication** | 0x0B | Proses autentikasi | ✅ |
| **Association Request** | 0x00 | Minta join | ✅ |
| **Association Response** | 0x01 | Respon join | ✅ |
| **Reassociation** | 0x02 | Pindah AP | ❌ |
| **Deauthentication** | 0x0C | Putus koneksi | ✅ |
| **Disassociation** | 0x0A | Keluar dari BSS | ❌ |

#### 1.5.2. Control Frames (Type 1)

| Subtype | Hex | Fungsi |
|---------|-----|--------|
| **RTS** | 0x1C | Request to Send |
| **CTS** | 0x1D | Clear to Send |
| **ACK** | 0x1D | Acknowledgment |
| **Block ACK** | 0x0C | Multiple ACK |

#### 1.5.3. Data Frames (Type 2)

| Subtype | Fungsi |
|---------|--------|
| **Data** | Data payload |
| **Null Data** | Keep-alive |
| **QoS Data** | Prioritized data |

### 1.7. Keamanan WiFi

#### 1.7.1. Evolusi Keamanan

```
WEP (1997)  → 🔴 TIDAK AMAN (crackable)
    ↓
WPA (2003)  → 🟡 Kurang aman (TKIP)
    ↓
WPA2 (2004) → 🟢 AMAN (AES) - STANDAR SAAT INI
    ↓
WPA3 (2018) → 🟢 LEBIH AMAN (SAE, GCMP)
```

#### 1.7.2. Metode Autentikasi

| Metode | Deskripsi | Keamanan |
|--------|-----------|----------|
| **Open System** | Tidak ada auth | ❌ Tidak aman |
| **WEP** | RC4 encryption | ❌ Rusak |
| **WPA-PSK** | Pre-shared key + TKIP | ⚠️ Lemah |
| **WPA2-PSK** | Pre-shared key + AES | ✅ Aman |
| **WPA2-Enterprise** | 802.1X + RADIUS | ✅ Sangat aman |
| **WPA3-SAE** | Dragonfly handshake | ✅ Lebih aman |

#### 1.7.3. Serangan Umum

```
🔴 Evil Twin     → AP palsu
🔴 Deauth Attack → Putus koneksi paksa
🔴 KRACK         → WPA2 key reinstallation
🔴 Brute Force   → Coba semua password
🔴 Rogue AP      → AP tidak resmi
```

### 1.8. Implementasi Praktis

#### 1.8.1. Minimal Beacon dalam C

```c
// Build beacon frame
int build_beacon(uint8_t *buf, uint8_t *bssid, char *ssid) {
    wifi_hdr *hdr = (wifi_hdr*)buf;
    uint8_t *pos = hdr->payload;
    
    // Frame Control: Beacon (0x8000)
    hdr->frame_control = htons(0x8000);
    
    // Address: Broadcast
    memset(hdr->addr1, 0xFF, 6);
    memcpy(hdr->addr2, bssid, 6);
    memcpy(hdr->addr3, bssid, 6);
    
    // Beacon body
    memset(pos, 0, 8); pos += 8;  // Timestamp
    *pos++ = 0x64; *pos++ = 0x00; // Interval
    *pos++ = 0x01; *pos++ = 0x00; // Capability
    
    // SSID
    *pos++ = 0;  // Tag SSID
    *pos++ = strlen(ssid);
    memcpy(pos, ssid, strlen(ssid));
    pos += strlen(ssid);
    
    return pos - buf;
}
```

#### 1.8.2. Raw Socket di Linux

```c
// Kirim frame via raw socket
int send_frame(int sock, uint8_t *buf, int len, const char *iface) {
    struct ifreq ifr;
    struct sockaddr_ll addr;
    
    strcpy(ifr.ifr_name, iface);
    ioctl(sock, SIOCGIFINDEX, &ifr);
    
    addr.sll_family = AF_PACKET;
    addr.sll_protocol = htons(ETH_P_ALL);
    addr.sll_ifindex = ifr.ifr_ifindex;
    addr.sll_halen = 6;
    
    return sendto(sock, buf, len, 0, 
                  (struct sockaddr*)&addr, sizeof(addr));
}
```

### 5.3. Praktikum

#### Praktikum 1: Build Beacon Frame (C)
```c
#include <stdio.h>
#include <string.h>
#include <stdint.h>
#include <arpa/inet.h>

typedef struct {
    uint16_t frame_control;
    uint16_t duration;
    uint8_t addr1[6];
    uint8_t addr2[6];
    uint8_t addr3[6];
    uint16_t seq_ctrl;
    uint8_t payload[];
} __attribute__((packed)) wifi_header_t;

int build_beacon(uint8_t *buf, uint8_t *bssid, char *ssid, int channel) {
    wifi_header_t *hdr = (wifi_header_t*)buf;
    uint8_t *pos = hdr->payload;
    
    hdr->frame_control = htons(0x8000);
    hdr->duration = 0;
    memset(hdr->addr1, 0xFF, 6);
    memcpy(hdr->addr2, bssid, 6);
    memcpy(hdr->addr3, bssid, 6);
    hdr->seq_ctrl = 0;
    
    memset(pos, 0, 8); pos += 8;
    *pos++ = 0x64; *pos++ = 0x00;
    *pos++ = 0x01; *pos++ = 0x00;
    
    *pos++ = 0;
    *pos++ = strlen(ssid);
    memcpy(pos, ssid, strlen(ssid));
    pos += strlen(ssid);
    
    *pos++ = 1; *pos++ = 4;
    *pos++ = 0x82; *pos++ = 0x84;
    *pos++ = 0x8B; *pos++ = 0x96;
    
    *pos++ = 3; *pos++ = 1; *pos++ = channel;
    
    return pos - buf;
}

int main() {
    uint8_t buf[256];
    uint8_t bssid[6] = {0x02, 0x11, 0x22, 0x33, 0x44, 0x55};
    int len = build_beacon(buf, bssid, "FreeWiFi", 6);
    
    printf("Beacon built: %d bytes\n", len);
    for (int i = 0; i < len; i++) {
        printf("%02x ", buf[i]);
    }
    printf("\n");
    return 0;
}
```
